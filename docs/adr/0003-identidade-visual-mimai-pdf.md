# ADR 0003: Identidade Visual "Mimai PDF", Slogan e Paleta Pantone 2026

- **Status**: Aceito
- **Data**: 2026-09-08
- **Decisores**: Equipe Mimai PDF

## Contexto
O aplicativo foi formalmente batizado como **Mimai PDF**, acompanhado do slogan característico *"mim não traduz, mim faz tradução"*. Era necessária uma identidade visual poética, moderna e que transmitisse leveza e elegância na manipulação de documentos e textos.

## Decisão
1. **Nome**: Mimai PDF.
2. **Slogan**: *"mim não traduz, mim faz tradução"*.
3. **Símbolo / Ícone**: Uma pena azul etérea caindo suavemente contra fundo branco minimalista, baseados nas tendências de cor Pantone 2026 (Airy Azure / Celestial Blue sobre Pantone Pure White).
4. **Formatos**:
   - Ícone raster icon.png (1024x1024).
   - Ícone Windows multi-resolução icon.ico (16x16 até 256x256).
   - Banner horizontal 16:9 (anner.png) para documentação e README.

## Consequências
- Identidade visual unificada em todos os pontos de contato (janela do app, barra de tarefas, executável Windows e documentação).
